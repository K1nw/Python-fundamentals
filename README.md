# Python Fundamentals

Repositório dedicado à prática contínua dos fundamentos da linguagem Python.

## Objetivos

- Revisar conceitos básicos.
- Consolidar conhecimentos.
- Praticar lógica de programação.
- Evitar o esquecimento dos conteúdos.
- Criar uma base sólida para projetos futuros.

## Conteúdos

- Variáveis
- Operadores
- Condicionais
- Laços (`for` e `while`)
- Listas
- Tuplas
- Dicionários
- Funções
- Módulos
- Manipulação de arquivos
- Tratamento de exceções
- Programação Orientada a Objetos

## Tecnologias

- Python 3
